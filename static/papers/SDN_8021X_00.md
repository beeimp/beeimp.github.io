## 서론

- SDN은 향상된 네트워킹 기능을 제공하는데 초점을 맞추고 있지만, 몇 가지 보안 문제와 우려를 가짐
- SDN에는 보안 기능이 기본 내장되어 있지 않아 네트워크 취약성 및 위협의 출현을 초래할 수 있음
- OpenFlow 기반 SDN 아키텍처는 여러 공격 벡터를 발생시킬 수 있음

  - 핑거프린팅/스케닝 패시브 공격

    1. 취약한 SDN 구성요소를 찾음
    2. 액티브 서비스를 식별
    3. 포트 오픈
    4. 전체 네트워크 토폴로지를 IP 주소에서 그려 추가 공격에 대한 계획을 용이하게 하기 위해 트래픽 분석, 정보 수집 및 분석

  - 중간자 공격을 통한 DoS 공격

- 스위치가 SDN의 주요 로컬 출입문이기 때문에, 이 출입문을 보호할 것을 제안
- IEEE 802.1x는 동적 VLAN 할당을 용이하게 하는 안전하고 유연한 인증 메커니즘을 제공
- 이 논문에서는 액세스 제어 메커니즘에서 확장성이 설계 고려 사항인 신뢰할 수 있는 하이브리드 아키텍처를 제공할 것

## 이론적 배경

### FlowNAC - [8]

- IEEE 802.1x 표준의 수정된 버전
- Flow 특성에 따라 액세스를 승인할 수 있는 장점을 가짐
- 각 서비스가 특정 흐름으로 식별되는 여러 서비스에 대해 네트워크 액세스 보장
- 주요 목적은 세분화된 흐름 기반 네트워크 액세스 제어를 수행
- but, 인증 지연이 있음

### AuthFlow - [9]

- IEEE 802.1x를 기반으로 자격 증명을 사용하여 호스트 ID를 확인하고 권한을 결정
- RADIUS 서버를 사용하여 EAP 채널을 통해 신청자로부터 받은 자격 증며을 기반으로 LDAP 데이터베이스에 대해 호스트 인증
- 사용자 이름과 암호 조합을 사용하드는 EAP 인증 방법에서 MSCHAP v2를 사용

### OpenFlow 기반 유연한 접근 관리 시스템 - [10]

- VLAN 대신 가상 네트워크 그룹 ID(GID)를 기반으로 함
- GID는 OpenFlow 컨트롤러의 추가 기능인 AMF(Access Management Function)에서 관리
- AMF는 가상 그룹 GID의 데이터베이스, 출발지 및 목적지 주소 확인 기능, 접근 제어 목록 확인 기능으로 구성
- 제안된 시스템은 eduroam에 도입
- but, 대규모 데이터베이스와 복잡성으로 인해 높은 유지 관리 프로세스가 필요
- 시스템은 PEAP(Protected Extensible Authentication Protocol) 및 EAP-TTLS와 같은 일부 EAP 방법에서 제공하는 익명 사용자 인증 모드를 지원하지 않음

### 무선 LAN 로밍에 대한 액세스 제어 시스템 제안 - [11]

- 연구기관과 교육기관 간의 무선랜 로밍을 위해 Trans-European Research and Education Network Association에서 제안한 기존의 eduroam 시스템의 단점을 지적

  - eduroam은 IEEE 802.1x와 RADIUS 프록시의 계층적 트리에 의존

- edurom은 EAP 방식에 따른 몇 가지 제한 사항과 데이터베이스의 유지 관리 비용으로 인해 어려움을 겪음

### 확장성 및 성능에 대한 이론적 분석과 실험 분석

#### 이론적 분석

- 확장성 향상을 위한 여러 기법 분석

  - 컨트롤러 능력 향상 - [13]

    - 네트워크 제어 어플리케이션을 개발과 정책 시행에 용이하지만, 컨트롤러에 과부하 발생으로 인한 네트워크 운영의 병목 현상 가능성 존재

  - 분산 이벤트 기반 Control Plane - [14]
  - 일부 관리 기능을 Data Plane에 위임 - [15]

- 전체 네트워크 성능(ex: 지연 시간, 지터, 처리량 및 오류율)에 어떤 영향을 미치는지 분석

  - 아키텍처에서 확장성과 네트워크 성능 문제
  - 인증에 소요되는 실행 시간이 다른 매커니즘에 비해 오래 걸리는지 시간 복잡성을 계산

## 결과

- SDN 컨트롤러에 IEEE 802.1x 기능을 포함시키는 것은 확장성, 보안, 성능의 문제를 해결

  - 사용자 ID를 직접 확인하고 인증자 기능을 레거시 스위치로 이관함으로써 확장성 및 보안 문제 해결
  - IEEE 802.1X 레거시 스위치를 삽입하면 데이터 링크 계층에서 작동하므로 네트워크 제어가 향상되고 식별 및 확인을 위해 네트워크 또는 애플리케이션 계층으로 확대할 필요가 없음
  - 인증 흐름은 신분 확인/검증에 관여하는 네트워크 구성요소에 도달하기 위해 더 긴 경로를 밟지 않아도 됨
